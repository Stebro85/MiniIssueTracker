# Mini Issue Tracker

> 🚧 Work in Progress

Mini Issue Tracker is a small learning project built with C# and .NET.

The goal of this project is to strengthen my understanding of the fundamentals of software development by
building an issue tracker step by step.

The project is currently under active development. Features, structure, and documentation will evolve as the project progresses.

## Current Focus

- Creating issues
- Issue types
- Issue priorities
- Issue statuses
- Basic input validation

More functionality will be added incrementally.
